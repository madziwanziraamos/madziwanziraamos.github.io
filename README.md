# Amos Madziwanzira — Frontend Portfolio

A static, responsive portfolio with projects and contact links. Built in vanilla HTML, CSS and JavaScript. No framework or build step required.

## Files

- `index.html` — content and page structure
- `styles.css` — visual styling and responsive layouts
- `script.js` — mobile navigation and dynamic footer year

## Live websites highlighted

- Global Climate & Power Engineering — https://globalclimateandpower.co.zw/
- Damsroads Innovative Solutions — https://damsroadsinnovativesolutions.liveblog365.com/

Other projects remain accurately labeled in progress, prototype, or local JavaScript work.

## Publish

Replace your `index.html`, `styles.css` and `script.js` at the root of the `madziwanziraamos.github.io` repository. See `../START_HERE.md` for details.
