# Amos Madziwanzira — Software Apprenticeship Portfolio Starter

A responsive single-page website using plain HTML, CSS, and JavaScript. No Node.js installation is required.

## Before publishing

1. Review your name, email address, and project descriptions in `index.html`.
2. Replace or expand project statements **only with work you can personally explain and demonstrate**.
3. Add links to any **real, publicly available** live demos or source repositories when they exist. Do not invent project URLs.
4. Get client permission before showing proprietary code, client photos, credentials or confidential project information.
5. Check layout on mobile and desktop. Verify navigation and mail links.
6. Do not claim projects labeled *in progress* have been launched.
7. If no project repositories are publicly viewable yet, create small original projects and upload them first.

## Preview on your machine

Open `index.html` in a web browser. You can also use the VS Code Live Server extension (optional).

## Publish free with GitHub Pages

1. Create/sign in to GitHub: https://github.com/
2. Create a public repository named `<your-username>.github.io` if using this as your main personal site.
3. Upload `index.html`, `styles.css` and `script.js` into the repository root.
4. Navigate to **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Choose `main` and `/ (root)` and save.
6. Open `https://<your-username>.github.io` when deployment completes.

Official reference: https://docs.github.com/en/pages/quickstart

## First GitHub assignment (Day 1)

**Goal:** Make this a project you understand, can explain, and have personally improved.

1. Open `index.html` in VS Code. Read the code for the hero paragraph, navigation, and project cards.
2. Edit the hero sentence to describe **your own** strengths and goals in your own words.
3. Replace one general project description with 2 specific, truthful things you personally contributed.
4. Review and verify the contact email before publishing.
5. Open `index.html` locally; check the desktop view and use your browser's mobile preview.
6. Open `script.js` and explain how the hamburger menu works.
7. Publish the site to your new GitHub repository; make the initial commit.
8. After one further code improvement, commit again with an honest message such as `Improve hero copy and mobile navigation`.

**Starter-code transparency:** This portfolio starter was prepared with AI assistance. Before using it as proof of your development skills, customize it, test the code, and be prepared to explain your own changes. Do not claim you independently wrote code you did not write.

**Never commit:** API keys, client secrets, passwords, identity documents, or private client files.
