# Your first GitHub repository — practical steps

## A. Register and secure an account
1. Visit https://github.com/signup and register with an email you control.
2. Choose a professional username (e.g., a variation of your own name).
3. Verify email and enable two-factor authentication.

## B. Upload your own portfolio
1. Download and extract the included files.
2. Edit `index.html` with accurate claims and your confirmed email.
3. Create a **public** repository called `<username>.github.io` for your personal portfolio (replace `<username>` with your actual handle).
4. Upload `index.html`, `styles.css`, `script.js`, and `README.md` into the repository root.
5. In the repository, open **Settings > Pages**, select **Deploy from a branch**, choose `main` and `/(root)`; click Save.
6. When Pages deployment is complete, open `https://<username>.github.io` and test the links.

## C. First independent improvement
1. In your code editor, change the intro copy to your own wording.
2. Add one truthfully described improvement to `README.md`.
3. Upload the updated files or use Git and push a commit with a descriptive message.
4. Share your GitHub repository URL and website URL for a practical code review.

## D. Before applying
- Do not upload private client assets without permission.
- Do not publish phone/email that you don't want public.
- Distinguish draft projects from live deployments.
- Be prepared to explain each HTML, CSS and JavaScript feature.

Official GitHub Pages docs: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
